## Call to Action: Secure the future maintenance of Xtext

As you might have recognized, the number of people contributing to Xtext on a regular basis has declined over the past years and so has the number of contributions. At the same time the amount of work for basic maintenance has stayed the same or even increased with the new release cadence of Java and the Eclipse simultaneous release. Briefly: The future maintenance of Xtext is at risk, at least in the current form and as part of the Eclipse Simrel. If you care, please join the discussion in [https://github.com/eclipse-xtext/xtext/issues/1721](https://github.com/eclipse-xtext/xtext/issues/1721).

## Changes

- Xtext 2.45 is built and tested against Eclipse 2026-12. Note that parts of the Eclipse 2026-12 release train require Java 25.
- The new project wizard now selects the Eclipse platform release train that matches the selected Java version, so projects generated for Java 21 resolve their target platform again.
- New opt-in `BracePairFoldingRegionProvider` that creates folding regions for matching brace pairs from the tokens of the configured `IBracePairProvider` instead of the EObject tree ([#3795](https://github.com/eclipse-xtext/xtext/issues/3795)).
- The `StandardLanguage` generator configuration now supports an (opt-in) code mining fragment, enabled via `codeMining = { ... }` ([#3810](https://github.com/eclipse-xtext/xtext/pull/3810)).
- `EmbeddedEditorFactory.Builder.showOverviewRuler()` (since 2.45) lets embedded editors show error, warning and info markers on the overview ruler ([#3796](https://github.com/eclipse-xtext/xtext/issues/3796)).
- Fixed lost queued URIs when a build is cancelled and `QueuedBuildData` is rolled back.
- Fixed a `ConcurrentModificationException` when reading `Stopwatches` data ([#3839](https://github.com/eclipse-xtext/xtext/issues/3839)).
- Build infrastructure updates: Tycho 5.0.4, Gradle 9.9.2, MWE, Guava, ClassGraph, Hamcrest 3.0, the Maven plugins and updated Orbit dependencies.
- This release also contains a number of smaller bug fixes and improvements.

## Performance

- `SimpleAttributeResolver` no longer takes global locks for plain attributes, removing a major contention point during parallel builds and linking.
- `PolymorphicDispatcher` keeps its method cache across garbage collections.

## Breaking Changes

- The default Java version for generated code changed from Java 8 to **Java 21** (`GeneratorConfig`, Xbase builder preferences, `JavaDerivedStateComputer`, `InMemoryJavaCompiler` and `OnTheFlyJavaCompiler2`). If you still need to generate code for an older Java version, configure the Java version explicitly.
- Wizard-generated Tycho projects no longer produce `*.feature.source` features; source bundles are included in the repository via `includeAllSources` instead.
